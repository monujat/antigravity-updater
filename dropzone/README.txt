==============================================================================
                    ANTIGRAVITY IDE UPDATE DROPBOX
==============================================================================

How to update Antigravity IDE easily:

1. When you download a new version of Antigravity IDE (e.g., .tar.gz, .zip, .dmg,
   or extracted folder), paste it right here into this folder.

2. Run the updater shortcut in this folder:
   - Linux:   Double-click "Update-Now.desktop"
   - macOS:   Double-click "Update-Now.command"
   - Windows: Double-click "Update-Now.cmd"

3. The updater will automatically:
   - Scan for the latest release candidate in this box and ~/Downloads
   - Safely backup your current installation to a .bak folder
   - Extract and install the update cleanly
   - Reconfigure binaries, shortcuts, and permissions
   - Notify you when complete and offer to launch Antigravity IDE!

You can also run `update-antigravity` from your terminal or command prompt anytime.
